# Data sources

## Vocabulary

`index.json` and `books.json` are generated by `npm run data:import` from
[complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary)
(© Yanis Zafirópulos, MIT license) — official HSK 2.0 (levels 1–6) and HSK 3.0
(levels 1–9) word lists with pinyin and English meanings.

**Lessons are derived, not official.** The upstream dataset contains no lesson
numbers, so words inside a book are sorted by corpus frequency and chunked into
lessons of 15–50 words (`lessonPolicy` in `books.json`). This grouping only
affects how vocabulary is sliced for practice sessions.

## Stroke paths

Stroke outlines and medians come from
[hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) (MIT), which
distributes the data from Make Me a Hanzi. Runtime loading order:

1. in-memory cache
2. IndexedDB cache (previously fetched characters)
3. network fetch from jsDelivr (`hanzi-writer-data`)
4. offline bundle `src/data/strokes/hsk1.json` (built by `npm run data:strokes`)

If none of these are available the app keeps working: hints and stroke-accurate
evaluation degrade to an ink-shape fallback and the UI explains why.
